# 24時間スケジュール管理アプリ

## 概要

1日の時間の使い方を可視化し、予定を管理するためのWebアプリケーションです。

開始時間・終了時間・タスク名を登録し、1日の予定を24時間の円グラフで表示することを主な目的としています。

予定を一覧で確認するだけでなく、時間の使い方を視覚的に把握することで、日々のスケジュール管理や時間の有効活用をサポートします。

## 開発の背景・目的

日々の予定を管理する際、予定の内容や時間を確認するだけでは、1日の時間をどのように使っているのか把握しにくいと感じました。

そこで、1日の予定を円グラフで可視化し、時間の使い方を直感的に理解できるスケジュール管理アプリを開発します。

本開発では、Webアプリケーションの設計・実装を通して、JavaScriptやReactの基礎、UI設計、データ管理について学ぶことも目的としています。

## 主な機能

### 必須機能

- **24時間の円グラフ表示**
  - 0:00〜24:00の時間配分を可視化
  - 予定の開始時間と終了時間に応じて表示を更新
  - 予定のない時間も把握できる表示を目指す

- **予定の登録**
  - 開始時間
  - 終了時間
  - タスク名
  - 詳細メモ（任意）

- **予定の編集・削除**
  - 登録した予定の内容を変更
  - 不要になった予定を削除

### 今後実装予定の機能

- 月間カレンダー表示
- 日付ごとのスケジュール管理
- 予定の分類（授業・就活・アルバイト・プライベートなど）
- 分類ごとの色分け表示
- ブラウザへの予定データの保存
- 入力内容や時間の重複に関するチェック

> ※機能の実装状況に応じて、この一覧を更新します。

## 技術構成

| 技術 | 用途 |
| --- | --- |
| HTML | Webページの構造 |
| CSS | レイアウト・デザイン |
| JavaScript | 予定管理・時間計算 |
| React | UIの構築・状態管理 |
| Vite | 開発環境・ビルド |
| SVG | 円グラフの描画 |
| localStorage | ブラウザ内へのデータ保存（導入予定） |

## 技術選定の理由

### React

カレンダー、予定入力フォーム、円グラフなどを部品ごとに分けて管理するために採用します。

予定の登録や編集に合わせて、関連する画面を更新しやすい構成を目指します。

### Vite

開発環境を簡単に構築し、コードの変更をブラウザですぐに確認しながら開発を進めるために採用します。

### SVG

予定の開始時間と終了時間から円グラフの角度を計算し、時間の長さに応じた表示を実現するために使用します。

### localStorage

初期段階ではサーバーやデータベースを用意せず、ブラウザ内に予定データを保存することで、基本機能を早い段階で完成させることを目指します。

## 開発環境のセットアップ

### 必要な環境

- Node.js
- npm
- Visual Studio Code（推奨）

### インストール方法

リポジトリを取得した後、プロジェクトのディレクトリで以下のコマンドを実行します。

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ターミナルに表示されるURLをブラウザで開くと、開発中のアプリケーションを確認できます。

### ビルド

```bash
npm run build
```

本番公開用のファイルを生成します。

## 開発方針

本アプリは、基本機能を確実に完成させることを優先し、段階的に機能を追加します。

1. 24時間の円グラフを表示する
2. 予定の登録・編集・削除を実装する
3. 時間配分の計算と円グラフの連動を実装する
4. データの保存機能を実装する
5. 月間カレンダーと日付ごとの管理機能を追加する
6. 予定の分類・色分けを実装する
7. 動作確認・UI改善・Web公開を行う
